## SIP_APP — Автоматический SIP-бот для трансляции музыки в звонки

**Что это:** Десктопное Python-приложение с GUI (PySide6), которое регистрируется как SIP-аккаунт в АТС (Mitel MX-ONE по конфигурации) и автоматически отвечает на входящие звонки, проигрывая в них аудио — либо из локальной папки с медиафайлами, либо из системного loopback-устройства (т.е. любых звуков, воспроизводимых на ПК).

---

### Архитектура

Проект разделён на два пакета:

**1. `sipbot/` — ядро (бэкенд)**
| Файл | Назначение |
|---|---|
| `core.py` | `SipBotCore` — главный контроллер: жизненный цикл потока, создание pjsua2 Endpoint, SIP-транспорт (UDP), регистрация аккаунта, watchdog регистрации, команды старт/стоп/рестарт, runtime-настройки (меняются без перезапуска) |
| `account.py` | `BotAccount` — класс аккаунта pjsua2: приём входящих звонков (`onIncomingCall`), автоответ 200 OK, режимы single/broadcast, управление списком звонков |
| `call.py` | `BotCall` — обработка каждого звонка: плейлист-поток (loop/shuffle/repeat_one), передача медиа через ffmpeg в loopback-синк PulseAudio, проброс capture-устройства в звонок (loopback-режим), локальный мониторинг аудио, скип треков |
| `audio.py` | `AudioManager` — работа с аудио: создание null-sink (`sipbot_sink`) через pactl, автовыбор capture/playback устройств, ffprobe длительности, MediaPlayerProcess (запуск ffmpeg + перенаправление в нужный sink) |
| `config.py` | `SipBotConfig` — dataclass со всеми настройками |

**2. `gui/` — интерфейс (фронтенд)**
- `window.py` — `MainWindow`: панель управления (Control Center) с формой SIP-аккаунта, настройками медиа, слайдером громкости, таблицей активных звонков и логом с цветовой разметкой
- `config.py` — загрузка/сохранение `data/config.json`, пути, цвета логов
- `bridge.py` — Qt-сигналы (log/state/calls) для потокобезопасной передачи событий из рабочих потоков в GUI

### Ключевые возможности

- **Автоответ на входящие SIP-звонки** (код 200 OK), поддержка до 32 одновременных звонков
- **Режимы звонков:** `single` (новый звонок сбрасывает старый) и `broadcast` (все звонки активны одновременно)
- **Источники медиа:**
  - `media` — файлы из папки (wav, mp3, ogg, flac, opus и др.) через ffmpeg → PulseAudio null-sink → pjsua2 capture
  - `loopback` — прямое пробрасывание системного capture-устройства (PipeWire/Pulse) в звонок
- **Режимы воспроизведения:** loop, shuffle, repeat one; ручной скип треков (пред/след) во время звонка; история воспроизведения
- **Регулировка громкости** передачи (0–200%)
- **Локальный мониторинг** аудио звонка на колонках (опционально)
- **Runtime-применение настроек** без перезапуска бота (во время активного звонка)
- **Watchdog регистрации:** мониторинг статуса, автоперерегистрация при потере/протухании
- **Автосоздание loopback-синка** `sipbot_sink` (PulseAudio/PipeWire) при старте
- **Desktop-интеграция:** установка `.desktop`-файла, иконка, тёмная тема (data/dark.qss)

### Технологии
- **Python 3** + **PySide6** (GUI) + **qtawesome** (иконки)
- **pjsua2** — SIP-стек (регистрация, звонки, аудио-медиа)
- **ffmpeg / ffprobe** — декодирование и передача аудио
- **PulseAudio / PipeWire** (`pactl`) — виртуальные sink/source для маршрутизации звука
- Запуск — через `run.sh` (активирует venv `sipenv`), установка pjsua2 описана в `pjsua2_setup*.sh`

### Типовой сценарий работы
1. Пользователь запускает приложение → создаётся/проверяется `sipbot_sink`, бот регистрируется на АТС (статус «Online»)
2. Абонент АТС звонит на номер бота → входящий звонок автоматически принимается (200 OK)
3. Если источник `media` — бот запускает ffmpeg-плейлист из папки; если `loopback` — пробрасывает системный звук
4. GUI показывает активных звонивших в таблице (ID, номер, статус, длительность) с кнопкой сброса каждого
5. По завершении аудио (media-режим) бот переходит к следующему треку, пока не сбросит звонок

По сути это **автоответчик-«музыкальный автомат»** для SIP-АТС: позвонивший абонент слышит музыку/звук с ПК, а оператор видит всех подключившихся и управляет воспроизведением в реальном времени.
